# 番茄小说桌面版

[▶ 观看宣传片](tools/promo/fanqie-desktop-promo.mp4)（30 秒，含配乐）

一个用 Rust 和 Tauri 写的 Windows 阅读客户端。目前主要在 Windows 11 上测试。

## 能做什么

- 搜索小说，查看推荐、目录和章节。
- 看书友推书帖的完整内容，以及接口返回的评论。
- 保存多个账号的登录状态，合并书架，也可以按账号筛选、搜索书名或作者。
- 阅读时优先使用读过这本书的账号，各账号的缓存和进度分开保存。
- 分页阅读，支持目录换章和页码跳转，窗口内也可切换全屏。
- 调整主题、字体、字号、行距、段距和版心；翻页操作可改、可删、可加。
- 老板键默认 Alt+Z 隐藏或恢复窗口，可在设置里改成其他组合键。

## 使用

推荐使用 Windows 安装包。双击 `番茄小说_0.1.0_x64-setup.exe`，按提示安装后可从桌面或开始菜单启动。缺少 WebView2 时，安装程序会联网从微软下载并安装；下载失败会提示重试，不会把运行环境未就绪当作安装完成。

免安装版仍可解压后运行 `fanqie-desktop.exe`，但需要自行准备 WebView2 Runtime。

添加账号会打开官方登录页面。账号数据保存在 `%APPDATA%\fanqie-desktop`，登录凭据使用 Windows DPAPI 加密，不会随程序打包。

## 从源码运行

需要 Rust、MSVC C++ 构建工具和 WebView2 Runtime。在项目根目录运行：

```sh
cargo run -p fanqie-desktop
```

构建正式版与运行测试：

```sh
cargo build --release
cargo test --workspace
```

`core` 是网络请求、字体解码与本地存储，`src-tauri` 是桌面端，`ui/dist/index.html` 是界面。界面资源会嵌入程序，修改后需要重新构建。

## 已知限制

这是非官方项目，与番茄小说没有隶属关系。只能显示接口能够获取的书架、阅读记录和评论，不保证包含手机端的全部历史。登录可能失效，届时需要重新登录；受限章节仍以账号权限为准。

目前真实热帖样本返回的评论数为 0，非空评论界面通过模拟数据测试，尚未验证真实社区帖的非空回复和评论分页。新账号的验证码、扫码流程需要实际完成登录后确认。
